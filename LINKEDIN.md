## Description

An interactive web application that simulates and visualizes memory allocation strategies using a parking lot scenario. Built with React, TypeScript, and Python, this educational tool demonstrates how Best-Fit, First-Fit, and Worst-Fit algorithms work in practice.

**Key Features:**
• Interactive simulation allowing custom parking space and vehicle size inputs
• Visual representation of three memory allocation strategies with real-time results
• Comprehensive analytics including space utilization metrics, success rates, and graphical visualizations using Chart.js
• Responsive UI built with Tailwind CSS and Shadcn/UI components
• Reference Python implementation demonstrating core allocation logic

**Technical Implementation:**
The frontend leverages React with TypeScript for type safety, Vite for optimized builds, and Chart.js for data visualization. The application processes user inputs to simulate vehicle allocation across parking spaces, calculating efficiency metrics like wasted space and allocation success rates. A standalone Python script provides an additional reference implementation using standard library functions.

**Impact:**
This project makes complex operating system concepts accessible through practical visualization, helping users understand resource allocation trade-offs. It demonstrates proficiency in full-stack development, algorithm implementation, and creating educational software.
